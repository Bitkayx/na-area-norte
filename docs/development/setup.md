# Development Setup

## Requirements

- Node.js
- pnpm
- Git

## Install

```bash
pnpm install
```

## Environment

Create:

```bash
.env
```

Required variables will be documented here as the PocketBase integration is implemented.

## Development

```bash
pnpm run dev
```

## Build

```bash
pnpm run build
```

## Validation

Run the appropriate lint/type/build checks before opening a PR.
